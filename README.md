# folder — 나의 할 일

온라인 작업 공간의 첫 연습 프로젝트로 만든 간단한 한국어 할 일 관리 앱입니다.
저장소의 장기적인 사용 목적은 아직 정하지 않았으며, 필요에 따라 바꿀 수 있습니다.

## 사용 가능한 기능
- 할 일 추가
- 완료 표시 및 해제
- 전체 / 진행 중 / 완료 목록 보기
- 할 일 삭제
- 같은 브라우저에 기록 자동 저장

## 처음 실행하기 (컴퓨터 기준)
1. 저장소에서 `index.html`을 클릭합니다.
2. 파일 화면의 **Download raw file** 버튼으로 내려받습니다. 버튼이 보이지 않으면 파일 화면의 `…` 메뉴를 확인합니다.
3. 내려받은 `index.html`을 Chrome, Edge, Safari 등 브라우저로 엽니다.
4. 할 일을 입력하고 **추가**를 누릅니다.

GitHub의 파일 화면은 소스 코드를 보여줍니다. 파일을 클릭하는 것만으로 앱이 실행되지는 않습니다.
현재 별도의 웹 주소로 배포하지 않았습니다.

## 저장 방식
할 일은 사용하는 브라우저의 localStorage에 저장됩니다.
GitHub 저장소에는 입력한 할 일이 올라가지 않습니다.
다른 기기와 자동으로 동기화되지 않으며, 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.
파일을 이동하거나 다른 브라우저로 열면 기존 기록이 보이지 않을 수 있습니다.

## 파일 구성
| 파일 | 설명 |
| --- | --- |
| README.md | 프로젝트 설명과 실행 방법 |
| index.html | 화면, 디자인, 동작이 들어 있는 앱 파일 |

자료가 늘어나면 `docs/`(문서), `assets/`(이미지 등), `archive/`(보관 자료)를 추가할 수 있습니다.
지금은 두 파일로 시작합니다.

## 수정 방법
1. GitHub에서 수정할 파일을 엽니다.
2. 연필 모양의 **Edit** 버튼을 누릅니다.
3. 내용을 수정하고 **Commit changes**로 저장합니다.
4. 컴퓨터에서 실행하려면 수정된 파일을 다시 내려받습니다.

Commit은 변경 내용을 기록하며 저장하는 기능입니다.
